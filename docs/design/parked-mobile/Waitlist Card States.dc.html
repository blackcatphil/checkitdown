POKER MAP ALPHA · ROOM CARD · WAITLIST CAPABILITY

Two card states, one rhythm

Waitlist is a per-room capability. The default card carries no trace of it — the footer row is freshness on the left, stakes on the right. When a room grants access, the stakes slot yields to a brass action in the same 44px row, so card height and list rhythm never change.

1 DEFAULT · NO WAITLIST
Footer row reads freshness → rake. Nothing missing, nothing disabled. Expanded, the only action is Directions — quiet, outlined, full width.
2 WAITLIST ENABLED · WYNN + WESTGATE
Collapsed: a brass-outlined pill with a live count, same row, same height. Expanded: filled brass, lit top edge, press travel, live seat detail — the one element that acts rather than reports.
RULE · FOOTPRINT Footer row is min-height 44px in both states, so an enabled card is exactly as tall as a default one.
RULE · ONE ACTION Brass fill is reserved for the waitlist commit. Everything else on the card is felt, ivory or grey — data, not buttons.
RULE · CLOSED ROOMS A closed room falls back to the default card even where access exists — no CTA that can’t be honoured right now.
