# Parked — mobile pass reference only

These are the pre-pivot mobile screens (402px, felt-green/brass, built around
crowd reporting, wait times and the waitlist button). NONE of it is the current
product.

They are kept because they are the pattern library for the eventual mobile pass —
stacked cards, sheets, one-handed nav, the 44px touch floor.

They are stale in SCOPE, not just palette. When mobile comes, do a fresh
responsive pass from the current six desktop surfaces and use these as reference,
rather than re-skinning them — re-skinning would carefully preserve features that
are not in v1.

poker-map-3d.html and poker-map-tier-a.html still carry the old chrome;
checkitdown-map-3d.html (one level up) is the re-skinned current module.
