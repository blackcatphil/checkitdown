# RoomPin

**Dim, never remove.** The filter answers "which of the seventeen match", and you can
only see that if all seventeen stay on the map. The extruded buildings dim with the
pins — a lit building under a dimmed pin is a contradiction the eye catches instantly.

Single click → glance popup with an explicit OPEN FULL DETAILS button (a popup that is
itself a link has no touch equivalent). Double click → the detail card.
