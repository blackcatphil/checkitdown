# ClusterPin

Three states, and the third is the one that gets forgotten:

- **all match** → solid `#5B8FD1`, plain count: `9`
- **some match** → outlined `#7FB0E8`, ratio: `1/9`
- **none match** → greyed outline: `0/9`

The ratio exists because dimming cannot represent a partial group. At city zoom the
Strip is one pin standing for nine rooms; if a filter matches one of them, opacity has
nothing to say and the number has to carry it.

**Selection stays blue.** Gold is decorative on this map — the cage, the road accents —
and a gold pin would make hue carry a data state.

Clicking zooms in. Street-level building massing is the reward for zooming, not the
entry state.
