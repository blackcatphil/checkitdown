# CompareChip

Header entry point into the comparison: `COMPARE 3 \u2192`, routing to Just the facts
with the set applied.

The set **dims non-picks in place and never reorders**. Ranks stay citywide — a
shortlist reads "#2, #4, #11", never renumbered 1-2-3. Rank position is the caution
signal in a ranked table; pinning would make position lie.
