# AccentAction

The single filled action per screen. Aubergine `#5E3A93`, hover `#6D45A8`, with a
1px `#A98CE8` lit top edge — that edge is the brand's tell and is not optional.

**One per screen.** Map → ADD TO COMPARE. Just the facts → the compare chip.
Tournaments → ADD TO CALENDAR. Promos → SEE WHAT IS BUILT. Everything else on the
page is data or a QuietAction.

Never use it for a destructive action, and never render two side by side.
44px minimum height even on desktop — mobile is coming.
