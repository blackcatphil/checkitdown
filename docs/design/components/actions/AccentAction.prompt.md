# AccentAction

The single filled action per screen. Steel blue `#1E4E86`, hover `#245C9C`, with a
1px `#7FB0E8` lit top edge — that edge is the brand's tell and is not optional.

**One per screen, and it is a CEILING rather than a quota.** Measured at rest, the
public surfaces carry zero: on this product the filled action appears on
interaction — the map popup's CTA, a checked filter box — rather than sitting on
the page. /install is the exception and carries the only resting one, and only
once the browser has actually offered an install prompt.

Never use it for a destructive action, and never render two side by side.
Never fill anything in gold: gold is decorative and carries no data meaning.
44px minimum height even on desktop.
