# RankCell

**Rank belongs to a sort, not to a room.** The column head must re-qualify with the
active sort (`# BY RAKE`, `# BY PARKING`) and these numbers must re-render with it.
A static rank beside a changing sort is a lie.

**The true #1 is weight, size and full-strength ink — never a colour.** 700 at 15px
in `--cid-text`; peers are 500 at 13px in `--cid-text-3`. The earlier teal marker
was retired with the aubergine palette: a best-in-city signal carried by hue is a
data state carried by colour, which the first rule forbids outright.

**That signal survives a compare dim**, because the personalisation is the dim and
the best-in-city fact is not personal. The dim is a COLOUR STEP, not an opacity —
`opacity` multiplies against the backdrop and took the lead to 3.76:1 and the peers
to 2.56:1, both below AA and unfixable by any palette.

**Never renumber a filtered view.** A shortlist reads `#2, #3, #11` — those are the
citywide positions and they are the whole point.
