# ExclusionNote

> "Wynn/Encore's rake is unverified — it collects by time, and we have not confirmed
> the figure with the room, so it cannot be ranked."

**Name the room, give the reason, offer the correction.** The wording changes with the
active sort: a room excluded from the rake ranking is not excluded from the freshness one.

This is the component that turns a hedge into an invitation, and it is why the product
can rank things at all without pretending to certainty it lacks.
