# EditorialRead

**Only where judgement fills a real gap.** Nobody publishes whether a daily tournament
actually fires, so watching and judging is the only way to have that information —
it belongs on Tournaments.

**Not on Just the facts.** Rake, drop, parking, food and tables are all published;
an editorial column there would dilute the one screen whose credibility rests on being
purely sourced. The name is the promise. Room-level colour belongs on Room Detail,
outside any ranked table — once an editorial value sits in a ranking, it starts
implying it can be ranked.

Never sortable, never colour-coded, never ordinalised. `cursor: auto`, not `pointer`.
