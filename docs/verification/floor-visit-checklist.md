# Check It Down - floor-visit verification sheet

_Derived from the seeded database 2026-08-05, main@1916d70. If seed data changes before the visit, re-derive._

## How to use this sheet

- Circle Y or N on EVERY amenity line. A blank is indistinguishable from "didn't look", and didn't-look is what this visit eliminates. "No" is a finding - record it proudly.
- Everything printed here is the database's current CANDIDATE claim, not a fact. CONFIRM means it matched what you saw or were told. If it's wrong, strike it and write what's true.
- For each answer, note HOW you know in the note space: posted sign, brush, floor supervisor, saw it yourself. That becomes the verification note.
- Game lists: a game we list that isn't spread sends someone across town for nothing - worse than a game we missed. Check every listed game AND write in anything running that we don't list.
- Tournaments: 13 of 17 rooms publish no schedule we can fetch. Photograph the schedule board and take any paper schedule at every room - at those 13 it is the only source we will ever have.
- Building heights are deliberately NOT on this sheet - the four height conflicts (Bellagio; Augustus, Julius and Nobu at Caesars) can't be settled from a poker room floor.

## What this visit must come back with

- Five conflicts to settle on the floor: Caesars Palace tables (16 vs 8) - Orleans tables (35 vs 34) - Westgate tables (7 vs 6) and its 3/6 limit game - Green Valley Ranch tables (15 vs 20) - Skyline's days.
- Rake numbers owed: ARIA, MGM Grand, Venetian, The Orleans and Skyline publish a cap but no percentage; Horseshoe publishes nothing at all. These rows block Just the Facts from ranking.
- Dress code and drinks policy are unpublished by every casino - ask both at all 17 rooms; this sheet is the only way those columns ever fill.
